## Решение заказчика по квоте (уровень 2, утверждено)

**Локальная модель через Ollama как резервный провайдер.** Не амендмент: три обязательных провайдера остаются интегрированными, добавляется четвёртый адаптер для dev/gate. Прод не затрагивается (localhost недостижим с Vercel; прод-цепочка остаётся `google`).

## Задание раунда

1. **Инвентаризация.** `ollama list` — какие модели стоят; `ollama ps`; проверь, отвечает ли `http://localhost:11434`. Выбери модель: приоритет — самая сильная из установленных, пригодная для структурного markdown (из типичных: qwen3/qwen2.5 ≥14b хорошо, llama3.1-8b слабовато, но сгодится). Если установленных нет или все слабые — предложи заказчику ОДНУ модель на скачивание с размером в ГБ и жди подтверждения (диск — его ресурс).
2. **Адаптер `ollama`** в `providers.ts` по образцу трёх существующих: OpenAI-совместимый endpoint (`http://localhost:11434/v1`) через `@ai-sdk/openai-compatible` (или эквивалент, который уже есть в зависимостях AI SDK; новую зависимость — только если без неё никак, с D-записью). Модель — константа `DEFAULT_MODELS.ollama` (как D-45). `OLLAMA_BASE_URL` — optional env с этим дефолтом. Ключа нет — правило D-46 для `ollama` требует не ключ, а доступность base URL не проверяет вовсе (недоступность = обычный отказ провайдера в цепочке, failover разберётся).
3. **Валидация живьём (локальные вызовы бесплатны — не экономь):** один полный цикл на чистой цепочке `ollama` — раунд интервью → резюме → генерация constitution с проверкой section schema → ревью. Если модель систематически заваливает структуру — попробуй следующую из установленных; всё завалили — честный рапорт с примерами, решение о скачивании за заказчиком.
4. **Добор Д-3:** живые вопросы, две идеи (техническая + бытовая), по два раунда — теперь на `ollama`, плюс, если суточная квота Google уже обновилась, один контрольный раунд на `google` для сравнения качества. Всё в `.gate-artifacts/questions.md` и в рапорт.
5. **Локальный дефолт для гейта:** `dev:gate` поднимается с цепочкой `google,ollama` — Google пока есть квота, локалка подхватывает при исчерпании; путь заказчика не стенится никогда. `.env` не переписывай молча — объясни в рапорте, что поменять (или сделай это флагом скрипта).
6. Юнит-тесты: адаптер в реестре, цепочка длины 2 с падением первого на 429 переходит на `ollama` (на стабах, как всегда), правило ключей не требует ключа для `ollama`.
7. Рапорт «Раунд 3» + обновлённая инструкция гейта для заказчика (те же две команды; отметь, что при исчерпании Google путь продолжается на локальной модели и что это ожидаемо медленнее).

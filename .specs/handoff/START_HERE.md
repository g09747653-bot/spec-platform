## Протокол handoff (новое правило, действует с этого раунда)

1. Точка входа каждой сессии — этот файл. Заказчик присылает только константную фразу; всё содержательное — здесь.
2. Останавливаясь (конец раунда или milestone, BLOCKED-стоп, нужны действия заказчика) — пиши полный рапорт в `.specs/handoff/REPORT-M<N>.md` по стандартной форме (СТАТУС / СДЕЛАНО / ТЕСТЫ-CI / DECISIONS / BLOCKED / НУЖНО ОТ ЗАКАЗЧИКА / СЛЕДУЮЩИЙ ШАГ). Новый раунд — новой секцией **сверху** файла, историю не затирай. Файл коммить вместе с работой.
3. В чат при остановке выводи ровно две строки: статус одной фразой + путь к рапорту. Больше ничего: Архитектор читает файлы проекта напрямую.
4. Правило закреплено в `CLAUDE.md` (п. 10) и `.specs/execution.md` §2 — перечитай оба.

Рапорт твоего первого раунда M0 Архитектор уже перенёс из чата в `REPORT-M0.md` (секция «Раунд 1»).

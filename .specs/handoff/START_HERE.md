## Порядок сессии (замена п.2 прежнего плана)

1. **Кандидаты эталона — до съёмки, кнопочным ходом.** 2–3 кандидата: лицензия поимённо (CC-BY / MIT / public domain; прямо допускает копирование и производные; имя, URL, где лицензия заявлена — в рапорт); сложность класса nvidia-страницы: многосекционный маркетинговый лендинг — hero-медиа, карточные сетки, анимации/интерактив, полная адаптивная линейка. Виджет заказчику — выбирает он.
2. **Операторская подготовка — вне рабочей директории, поимённо.** Свежие эталоны тем же харнессом по всей линейке брейкпоинтов + манифест (число кадров — по фактической высоте страницы); медиа-материал (изображения/шрифты/видео) — легально и целиком из дистрибутива/страницы. **HTML/CSS/JS оригинала в workspace не кладутся и исполнителю не показываются ни в каком виде.** В чистую директорию попадают только: эталоны+манифест, медиа, SEED.
3. **SEED — задумка-копия 1:1.** Тема, язык, состав/порядок секций и контент — как у оригинала. Знак: вымышленный бренд шаблона копируется как есть; настоящий чужой знак → нейтральный, зоны знака в замере отдельной строкой. Атрибуция CC-BY — строкой в README артефакта.
4. **Прогон конвейером, с нуля, без рук.** `start-loop` → классификатор (`coherent-artifact`) → цельный план (сборка целиком одной задачей + полировка по D-323 + замер) → исполнитель в контейнере строит С НУЛЯ → суд трёх осей (зелёный обязателен — планка продукта) → попиксельный замер против свежих эталонов, публикуется как есть (знак-зоны отдельной строкой, если применимо). Per-task таймауты ДО старта — законная настройка среды. Сужение брифов запрещено; ходы только кнопочные, поимённо.
5. **Итог заказчику**: алерт со сверкой + один вход; его глаза — приёмка бенчмарка.
6. **Рапорт** — секция «Бенчмарк А-37.1» сверху в REPORT-M17A.md, две строки в чат.

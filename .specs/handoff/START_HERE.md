## Р-1 — толерантность разбора черновика интервью (по п. 6(а))

Двухслойно, оба слоя обязательны:

1. **Парсер:** извлекается крайний сбалансированный JSON-объект; всё после закрывающей скобки отбрасывается (наблюдаемые случаи: хвостовая кавычка, точка). **Внутренности JSON не чинятся никогда** — сломанная скобка внутри остаётся невалидной. Тесты: оба наблюдаемых хвоста парсятся; внутренняя поломка — нет.
2. **Один автоматический повтор** полной генерации черновика на `DRAFT_INVALID` до показа ошибки пользователю. Ровно один; второй провал — прежний `DRAFT_INVALID` наружу. Тест: первый черновик бит → повтор → валидный → пользователь ошибки не видел; оба биты → ошибка как раньше.

Это изменение поведения M2-контракта «repair-once» — санкционировано: repair чинил структуру валидного JSON, Р-1 добавляет слой ниже (текст → JSON) и слой выше (повтор). Запиши D-94.

## Р-2 — обрыв чтения не отменяет прогон (по п. 6(б); отменяет решение раунда 2 в части cancel)

Корневой фикс, не подстройка констант:

1. **`cancel()` ридера больше не гасит вызов провайдера.** Серверный прогон доживает до естественного конца: пишет чанки, валидирует структуру, персистит ревизию, помечает run `complete`/`failed`. Комментарий «строка прогона и чанки остаются, клиент возобновится по ним» становится правдой.
2. **Ридер при переподключении** читает состояние run: `running` со свежим прогрессом → ждать дальше (бэкофф не исчерпывается, пока продюсер жив); `complete` → забрать ревизию; `failed` → показать ошибку. Дедлайн простоя 45 с остаётся как детектор обрыва соединения — теперь он безвреден, потому что переподключение находит живого продюсера.
3. **Предохранитель от вечного `running`** — серверный бюджет цепочки (`LLM_REQUEST_TIMEOUT_MS` × длина цепочки + ретраи), который и так завершает прогон. Никаких новых таймеров.
4. Тесты: медленная генерация (стаб с задержкой чанков > дедлайна ридера) при обрыве и переподключении доходит до ревизии; закрытие вкладки навсегда → прогон завершён, ревизия в БД, возврат на страницу показывает её; Stop из раунда 2 продолжает работать как явное действие пользователя (единственный легальный способ сказать «не жди»).
5. Замер из п. 6(б) повтори: генерации 46–50 с из браузера должны проходить. Запиши D-95.

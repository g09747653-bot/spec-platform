## Порядок M14а (задачи 148–151, читай их AC в tasks.md целиком)

1. **148 — авто-сессия владельца.** Ключевое сверх AC: одна точка подмены на том же шве, что читает `currentOwnerScope()`, — ни одной ветки «если локальный режим» ниже этого шва. 2. **149 — персистентный локальный профиль БД.** Тот же механизм, которому уже доверяет черновой харнесс (PGlite), но с данными в gitignored-каталоге проекта. Одна команда поднимает весь локальный стек, одна гасит; README-раздел для заказчика — три команды по-русски. Черновой гейтовый харнесс не трогать. AC про рестарт посреди пути — главный: сессия, ревизии, доски и реплики переживают перезапуск побайтово.
3. **150 — машинный экспорт бандла.** Режим рядом с ZIP, не замена. JSON выводится из ТЕХ ЖЕ одобренных ревизий, что печатает ZIP, — без отдельной генерации, без модели в петле, детерминированно. AJV-валидация по общим фикстурам — юнит-тест; golden-фикстура прибивает маппинг markdown→JSON; ZIP байт-в-байт как сегодня.
4. **151 — гейт M14а.** Живая прогулка локального профиля: стек одной командой, авто-сессия, полный автономный прогон от короткого русского seed до запечатанного бандла (профиль гейта: свежий ключ спереди; перед прогоном проверь, что фоновое приложение Ollama не держит окно 4096 — правило из A0), машинный экспорт валиден, рестарт dev-сервера посреди прогулки. Новое красное условие: любая OAuth-поверхность на экране в локальном режиме = красный. Артефакты `artifacts/gate-M14a/`.

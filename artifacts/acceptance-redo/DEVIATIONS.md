## T004 — извлечение общих ассетов (логотип, иконки, шрифты)

Извлечение выполнено полностью из уже сохранённых файлов `tools/visual-diff/baseline/source/{index,products}.html` и `tools/visual-diff/baseline/network/` (по `manifest.json`), без единого нового обращения к живому сайту — исключение из T007, предусмотренное заданием T004, не потребовалось: все нужные файлы уже были в перехвате T006.

- **Логотип**: полноцветный SVG-логотип NVIDIA (WordMark + eye mark, `viewBox="0 0 117 35"`) извлечён из инлайн-разметки `<a class="brand-link ... nvidia-logo">` в `index.html` → `assets/images/nvidia-logo.svg`. Файл `tools/visual-diff/baseline/network/logo_nvidia.png`, несмотря на имя, — это логотип виджета cookie-баннера OneTrust (`cdn.cookielaw.org`), а не логотип NVIDIA; он не использован.
- **Иконки**: 18 SVG-иконок глобального меню (менюшка/гамбургер, закрытие, стрелки-карет во всех направлениях, корзина, поиск, профиль пользователя, малая версия логотипа-символа) извлечены из блока `<!-- SVG SYMBOL DEFINITIONS -->` (`<symbol id="...">`) в `index.html`; идентичный набор символов подтверждён и в `products.html` → `assets/icons/*.svg`.
- **Иконки соцсетей футера** (Facebook, Instagram, LinkedIn, Twitter/X, YouTube) в оригинале — не отдельные файлы изображений, а глифы иконочного шрифта Font Awesome 6 (классы `fa-brands fa-facebook-f` и т.п.), которые уже покрыты извлечёнными файлами шрифтов `assets/fonts/font-awesome-6-brands-400.woff2` и т.д. Отдельных SVG/PNG-файлов для этих иконок в исходнике нет и извлекать нечего.
- **Шрифты**: все файлы шрифтов найдены в перехвате T006 и сопоставлены с URL из `manifest.json`:
  - `NVIDIASansVF_W_Wght.woff2` → `assets/fonts/nvidia-sans-variable.woff2` (переменный, используется как `font-family: "NVIDIA Sans"`)
  - `NVIDIASansVF_NALA_W_Wght.woff2` → `assets/fonts/nvidia-sans-nala-variable.woff2` (переменный, `font-family: NVIDIA-NALA`)

  - Точных правил `@font-face` (url/font-weight/font-style) в сохранённом исходнике нет — ни в `source/*.html`, ни в перехваченных сетевых ответах нет подключённого CSS-файла с этими правилами (в перехвате T006 CSS-файлы отсутствуют). Сопоставление семейства/начертания с файлом сделано по имени файла и по значениям `font-family`, встречающимся в инлайн-стилях `index.html` (`"NVIDIA Sans"`, `NVIDIA-NALA`). Уточнение конкретных весов/диапазонов переменных осей — на подключении шрифтов в CSS на последующих шагах.

## Меню/Футер

Сравниваются `partials/header.html`/`partials/footer.html`, включённые в `index.html` и `products.html` через `tools/build.js` (T005).

- **Стилизация шапки и футера отсутствует (все три ширины, `index` и `products`)**: `src/styles/header.css` и `src/styles/footer.css` физически не существуют в `src/styles/` (`ls` подтверждает: есть только `base.css`, `home.css`), хотя обе сгенерированные HTML-страницы их подключают. В результате шапка рендерится как неоформленный список ссылок (`NVIDIA` текстом вместо SVG-логотипа из `assets/images/nvidia-logo.svg`, пункты меню без выпадающих списков и иконок поиска/аккаунта/региона из `assets/icons/`), а футер — как обычный текстовый список без колонок/иконок соцсетей (сравните `baseline/index-1440-scroll0.png` и `clone/index/1440/scroll-0.png`). Это основная причина расхождений SC-001, приведённых в разделе «Главная страница» выше, применительно к области шапки/футера. Статус: **запланировано отдельно** (T014 для шапки, T015 для футера; вне объёма T023).
- **`header.top` на scrollY=0**: `index.html` — расхождение 166px (375px), 126px (768px), 108px (1440px); `products.html` — 211px (375px), 171px (768px), 167px (1440px). Во всех случаях `baseline` > 0, `clone` = 0 (клон: `header` — первый элемент `body`). Визуально (`baseline/index-375-scroll0.png`) над шапкой на оригинале показан региональный баннер «Visit your regional NVIDIA website…» с выбором страны — геолокационный виджет, требующий сети/JS стороннего сервиса, аналогично уже задокументированному в T004 исключению баннера cookie-согласия OneTrust. Офлайн-клон не воспроизводит подобные зависящие от сети виджеты по построению (FR-009 — отсутствие внешних сетевых запросов). Статус: **принято как неустранимое**.
- **`header.height` / `logo.height`**: в отчёте выглядит как FAIL (baseline=0, clone=72/17px), но это артефакт инструмента, а не факт с оригинала — во всех сохранённых baseline JSON (`index-*-scroll*.json`, `products-*-scroll0.json`) поля `header.height` и `logo.height` равны 0 на любой ширине и странице, включая сегменты, где шапка заведомо видна на скриншоте. Это означает, что селектор шапки/логотипа в `capture-baseline.js` (T006) на реальной DOM-структуре nvidia.com сматчился с элементом нулевой высоты, а не с фактической шапкой. Сравнивать высоту шапки/логотипа клона с этим полем некорректно; содержательное расхождение по стилю шапки уже отражено выше отдельным пунктом. Статус: **принято как неустранимое** (ограничение T006/T009).
- **Футер: сопоставление по `footer.topRelativeToContentEnd` не выполнено**: ни в одном сохранённом baseline-сегменте (`index-*-scroll0.json`, `products-*-scroll0.json`) нет поля `footer` — на baseline футер попадает в кадр только на больших scrollY (страница длиной ≥9000–17864px), а `compare.js` сопоставляет сегменты только в диапазоне `[0, min(maxScrollY_baseline, maxScrollY_clone)]`; поскольку клон короче (максимум 1058px), пересечение — только scrollY=0, где у baseline футера ещё нет в кадре. Числовое SC-002-сравнение футера станет возможным только после довёрстки секций главной страницы (T018) / карточек продуктов (T024–T026), когда высота клона приблизится к оригиналу. Статус: **запланировано отдельно** (T018 для index.html; T024–T026 для products.html).
- **Расхождений по горизонтальному отступу контента (`contentPadding.left`/`right`)** не обнаружено на всех проверенных сегментах (0px, PASS, ≤2px порога SC-002) — раздел «Меню/Футер» по этому конкретному отступу в дополнительной документации не нуждается.

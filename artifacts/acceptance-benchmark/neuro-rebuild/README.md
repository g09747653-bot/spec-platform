# Витрина NEURA 50 — один вход

## Как открыть

**Одно действие, любое из двух:**

- Windows — двойной щелчок по `start.cmd`
- macOS / Linux — `./start.sh`
- либо из терминала, где угодно: `npm start`

Поднимется локальный адрес (по умолчанию `http://127.0.0.1:4173/`), браузер откроется
сам, и работа будет видна целиком: главная, а из неё — вся навигация. Ходить по папке и
открывать файлы по одному не нужно и не предполагается.

Остановить — `Ctrl+C` в окне запуска.

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | Главная: герой, показатели, витрина-слайдер, технологии, сравнение «до/после», развороты, новости |
| `products.html` | Линейка: карточки моделей с диаграммами, таблица характеристик, вопросы |
| `assets/css/site.css` | **Одна** дизайн-система на весь сайт: токены → примитивы → компоненты → секции |
| `assets/js/site.js` | **Один** слой поведения: появления, слайдер, сравнение, гармошка, счётчики |
| `serve.js` | Локальный сервер одного входа |
| `assets/images`, `assets/icons`, `assets/fonts` | Материал витрины |

Обе страницы подключают один и тот же CSS и один и тот же JS. Ни одна секция не заводит
собственных цветов, отступов, шкал и длительностей — только токены из `:root`. Это и есть
ответ на «кнопки расходятся, дизайн съезжает»: расходиться нечему, потому что величина
одна на всех.

## Живость

Сайт двигается, и это проверяется, а не предполагается:

- **при наведении** — карточки приподнимаются, изображение внутри медленно наезжает, кнопки
  смещаются, ссылки раздвигают стрелку, строки таблицы подсвечиваются;
- **при прокрутке** — секции и карточки появляются лесенкой (`IntersectionObserver`), полосы
  диаграмм доезжают до своих значений, счётчики показателей считают;
- **само по себе** — витрина-слайдер перелистывается каждые 4,2 с, аврора в герое дышит,
  бегущая строка едет, подсказка прокрутки покачивается.

Слайдер останавливается под курсором и на спрятанной вкладке. При системной настройке
«меньше движения» анимации выключаются целиком — это часть требования, а не исключение из него.

## Материал

Изображения и шрифты в `assets/` — материал витрины, собранный конвейером ранее; страница
демонстрационная и никуда не публикуется. Тексты, вёрстка, дизайн-система, диаграммы и
таблицы написаны для этой витрины.

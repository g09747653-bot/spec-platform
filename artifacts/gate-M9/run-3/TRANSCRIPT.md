# GrantReminder Constitution

## Core Principles

### I. User-in-the-Loop Email Control (NON-NEGOTIABLE)
The system must never automatically send any emails under any circumstances. Automated background dispatch of emails is strictly prohibited. All drafts generated by the system must be displayed to the user for review, editing, and manual transmission. The founder-director always retains full, absolute control over when, how, and to whom an email is sent.

### II. Decoupled Email Delivery (Zero Integration)
To ensure reliability and speed of development, direct integration with external email services (such as SMTP, IMAP, Google Workspace OAuth, Microsoft 365, or SendGrid APIs) is explicitly out of scope for the initial version. The tool will generate and present perfectly formatted draft text within the user interface, accompanied by single-click actions to copy the content or open the user's native system mail client via standard mail links.

### III. Instant Draft Generation (The Magic Moment)
The absolute core value of the tool is the automated creation of context-aware email drafts. When a grant application deadline approaches, the system must automatically construct a tailored draft email utilizing the specific foundation name, the due date, the grant amount, and the tracking history. This draft must be immediately accessible to the user on the primary dashboard view without requiring complex configurations or navigation.

### IV. Anti-Spreadsheet Clarity
The product is built specifically to rescue founders from the "spreadsheet mess." The user interface must present information in a visual, chronological sequence that highlights urgency. Grid lines, highly dense text tables, and complex nesting of data sheets must be avoided in favor of a clean tracker cards, clear status badges, and prioritized alert banners.

The user profile is a multitasking founder-director who has limited time and zero tolerance for technical administrative overhead. ## Overview

The Grant Application Tracker and Email Drafter is a lightweight, single-user web application designed to help busy founders of small charities manage their fundraising pipeline. By replacing fragile, unmanaged spreadsheets with a dedicated database and an intuitive visual interface, the system eliminates the risk of missed grant deadlines—a critical vulnerability for understaffed organizations.

The system serves two core purposes:
1. **Deadline Tracking:** Presenting a clean, chronological dashboard categorized by urgency so that the founder has instant visibility into upcoming submissions and reporting milestones.
2. **Drafting Communications:** Generating predictable, template-based email drafts (such as internal task delegations, letters of support requests, or funder check-ins) associated with those grants on-demand.

To keep data-entry overhead low for the founder, the system implements an extremely simple "Add Grant" workflow that requires only three key fields to get started. To respect security and boundary limits, the application does not connect to external mail servers or send emails directly. Instead, it provides a specialized split-pane "Review & Export Workspace" where the user can refine and copy subject lines and email bodies directly to their system clipboard with a single click, then paste them into their preferred email client.

---

The application is explicitly designed for a single-user workflow. It does not support multi-tenant environments, organization hierarchies, or complex role-based access control.

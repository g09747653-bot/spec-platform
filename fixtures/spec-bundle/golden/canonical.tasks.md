# Implementation Plan

## Overview

Три фазы: каркас, ядро, доставка. Задачи пронумерованы сквозной нумерацией; каждая называет, чего
она ждёт.

## Phase 1 — Каркас

- [ ] 1. Инициализировать репозиторий и тулчейн
  - Node 22, TypeScript в strict-режиме, форматтер и линтер в CI.
  - _Зависимости: —_

- [ ] 2. Схема базы и первая миграция
  - Таблицы `notes` и `tags`, миграции версионируются в репозитории.
  - _Зависимости: 1_

## Phase 2 — Ядро

- [ ] 3. Репозиторий заметок
  - CRUD поверх схемы задачи 2, все входы валидируются на границе.
  - _Зависимости: 2_

- [ ] 4. HTTP-слой
  - Маршруты чтения и записи поверх репозитория.
  - _Зависимости: 3_

- [ ] 5. Полнотекстовый поиск
  - Индекс по заголовку и телу заметки.
  - _Зависимости: 2, 3_

## Phase 3 — Доставка

- [ ] 6. Сквозной тест критического пути
  - Создание заметки, поиск, удаление — одним прогоном.
  - _Зависимости: 4, 5_

- [ ] 7. Сборка и запуск одной командой
  - README с тремя командами и проверкой окружения.
  - _Зависимости: 6_
